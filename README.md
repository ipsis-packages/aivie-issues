# Aivie Content – issues

This is the public issue tracker for **Aivie Content**, the AI content package for Umbraco 17
(NuGet: [`Aivie.Content`](https://www.nuget.org/packages/Aivie.Content)).

The source code is not public. This repository only holds issues.

- **Documentation:** <https://docs.aivie.nl>
- **Release notes:** <https://docs.aivie.nl/release-notes>

## Before you open an issue

1. Check the [documentation](https://docs.aivie.nl), especially
   [Troubleshooting](https://docs.aivie.nl/troubleshooting).
2. Search the [existing issues](https://github.com/ipsis-packages/aivie-issues/issues?q=is%3Aissue), open and
   closed. If yours is already there, add a 👍 or a comment with your details instead of a new issue.
3. Update to the latest version of Aivie Content, if you can, and check that the problem is still there.

## Opening an issue

Choose **Bug report** or **Feature request** under
[New issue](https://github.com/ipsis-packages/aivie-issues/issues/new/choose). The form asks for what we need to
reproduce the problem: the versions of Aivie Content, Umbraco and .NET, the database, and the steps.

You may write in English or Dutch.

**Never post secrets.** Leave out API keys, licence keys, connection strings and the contents of
`appsettings.json`. Screenshots of the backoffice are welcome; check that they do not show a key.

## Not here

- **Licences, subscriptions and allowances:** contact your Aivie supplier.
- **Security problems:** do not open a public issue. Use
  [Report a vulnerability](https://github.com/ipsis-packages/aivie-issues/security/advisories/new) instead; only
  the maintainers can read it.
